# Project Template

This directory mirrors the target structure created inside the new user's home directory during the lab.

Expected lab structure after the required tasks:

```text
project/
├── docs/
│   └── report.txt
├── scripts/
│   ├── install.sh
│   └── report.txt
├── bin/
│   └── classified.txt
└── backup/
    └── copied contents from docs and scripts
```

The actual lab also creates and later deletes `docs/admin_notes.txt`.

This template is only a structural reference. It does not claim that the learner has created these files on Kali Linux.
