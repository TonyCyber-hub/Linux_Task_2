# Backup

This directory represents the repository location reserved for backup-related material.

The lab itself asks the learner to create a `backup` directory inside the Linux `project` directory and copy the contents of `docs` and `scripts` into it.

The repository-level `backup/` directory is kept separate from the learner's actual `~/project/backup` directory so that Git repository organization does not interfere with the lab.

Do not treat the presence of this folder as proof that the lab backup task was completed.
