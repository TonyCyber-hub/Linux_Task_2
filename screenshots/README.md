# Screenshots

Store screenshots proving your actual completion of the lab tasks here.

## Naming Convention

Use numbered names matching `EVIDENCE_CHECKLIST.md`, for example:

```text
01_user_created.png
02_sudo_group.png
03_whoami_student01.png
...
18_final_tree.png
```

For bonus evidence:

```text
20_history.png
21_commands_used.png
```

## Screenshot Guidelines

- Use PNG or JPG.
- Keep terminal text readable.
- Capture the command and relevant output together when practical.
- Avoid including passwords or other sensitive information.
- Do not create or upload screenshots that falsely represent task completion.

The `.gitkeep` file only preserves this empty directory in Git; it is not evidence of completion.
