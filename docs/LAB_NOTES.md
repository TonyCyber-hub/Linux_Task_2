# Lab Notes

## Source Lab

**Linux Command Line Practical Task**

## Objective

The supplied lab asks the learner to demonstrate basic Linux commands by completing tasks as a newly created user in Kali Linux.

## Required User

```text
student01
```

## Main Areas Covered

- User creation and switching
- Directory creation
- File creation and editing
- Hidden files
- Copying and moving files
- Shell script creation
- `chmod` permissions
- Cleanup
- Backup creation
- `tree` and `ls -la` verification
- Optional command history capture

## Important Required Content

`report.txt` begins with:

```text
This is the initial report by student01.
```

The second line added using nano is:

```text
Appended line using nano.
```

`.secret.txt` initially contains:

```text
Top Secret.
```

`install.sh` contains:

```bash
#!/bin/bash
echo "Installing project dependencies..."
```

The lab asks for `admin_notes.txt` to have owner read/write permissions only, and then asks for it to be deleted during cleanup.

## Completion Status

No task is represented as completed by this repository alone. Completion must be demonstrated by the learner's own Kali Linux terminal and evidence.
